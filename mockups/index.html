Performance plan

How these hit 100 on PageSpeed

  • No render-blocking third-party CSS/JSBootstrap 4, jQuery, Popper, Font Awesome, AOS, Unite Gallery, Google Fonts → replaced by one ~14 KB hand-written stylesheet (inline-able as critical CSS), inline SVG icons, a ~1 KB vanilla script, native popover menu and <dialog> lightbox.
  • System font stackNo webfont download, no layout shift. (Optionally self-host one subsetted variable WOFF2 with preload.)
  • ImagesExplicit width/height (zero CLS), loading=lazy, hero preloaded. Implementation step: generate responsive WebP/AVIF sizes for photography (25 MB) and illustrations (41 MB) once, with a script.
  • Third parties deferredGoogle Analytics, Disqus, Pageclip and Razorpay load after interaction / on idle, so they never block first paint.
  • Same SEO & metaThe <head> meta block, {% seo %}, manifest, theme-color, icons and RSS link are carried over verbatim.
